# nodus-rules

用于存放和维护远程规则集与远程插件集，为支持相应规格的应用提供远程资源。

## 上游与感谢

本项目参考并同步 [blackmatrix7/ios_rule_script](https://github.com/blackmatrix7/ios_rule_script) 的规则集，转换为 Nodus 格式。

感谢 blackmatrix7、该项目的贡献者以及其引用的规则作者。上游内容保留原许可与来源说明，具体见各集合 README。
